## Purpose

Compound Engineering defines a reusable workflow for building, fixing, reviewing, and debugging work safely.

## Commands

- `/ce-brainstorm` — explore what to build.
- `/ce-plan` — define scope, phases, and done.
- `/ce-work` — execute authorized work.
- `/ce-code-review` — review completed work.
- `/ce-debug` — troubleshoot failed or unexpected behavior.

## Workflow

1. Plan what you're building.
2. Define what "done" actually looks like.
3. Work through clear delivery phases.
4. Review the work and troubleshoot if needed.
5. Mark as done only after validation passes.

## Done Rule

No task is done until:

- scope matches authorization
- protected surfaces are respected
- validation passes
- regressions are checked
- unresolved issues are documented
- git status is understood
- commit/push status is explicit
