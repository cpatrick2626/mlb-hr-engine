# /ce-brainstorm

## Purpose

Explore what to build before planning or implementation.

Use when the operator has:

- a vague idea
- a feature concept
- a UX problem
- a bug pattern
- a workflow improvement
- a product concern
- multiple possible directions

## Output

```md
## /ce-brainstorm Result

### Problem / Opportunity
...

### Possible Approaches
| Option | Benefit | Risk | Effort |
|---|---|---|---|

### Best Small Version
...

### Better Later Version
...

### What Not To Build
...

### Recommended Direction
...

### One Next Action
...
```

## Rule

Do not jump directly to implementation.
