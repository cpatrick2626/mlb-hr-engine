# /internal-focus-group Setup

## Purpose

This guide explains how to add people or named personas to `/internal-focus-group`.

## Step 1 — Identify Real People or Named Personas

Examples:

- actual operator/user
- product user
- sharp bettor
- casual bettor
- mobile-first user
- TCC operator
- MAIN scanner
- JIG builder
- FanDuel-click user

A real person requires source-backed notes.

A persona must be clearly labeled as a persona.

## Step 2 — Ingest Source Material

Use:

`/ingest-source`

or alias:

`/ingest-resource`

Save material into:

`MLB HR ENGINE/knowledge/focus-group/{name}/`

## Step 3 — Capture Agent Profile

Each agent needs:

- name
- agent type
- source material
- voice cues
- lens
- known frustrations
- decision criteria
- evidence level

## Step 4 — Ask the Focus Group

Use:

```text
Use /internal-focus-group.

Test this before launch:
<idea/change/copy/feature>
```

or:

```text
Use /internal-focus-group.

Ask <name> what they think about:
<idea/change/copy/feature>
```

## Folder Standard

Canonical folder:

`MLB HR ENGINE/knowledge/focus-group/`

Do not use:

`focus-ygroup/`
