# /ask-the-board Default Board

## Purpose

This file defines the default advisory board for `/ask-the-board`.

The board is not literal impersonation. It is a set of expert-inspired decision lenses.

## Default Seats

| Seat | Lens | Primary Use |
|---|---|---|
| Sharp Betting Discipline | Billy Walters-inspired market discipline lens | Bet/pass, price sensitivity, bankroll discipline, market attack |
| Quant Edge Engine | Bill Benter-inspired quant edge lens | Probability, model structure, data quality, expected value |
| Product Strategy | Marty Cagan-inspired product strategy lens | What to build, what to cut, user value, roadmap discipline |
| Engineering Systems | John Carmack-inspired engineering clarity lens | Simplicity, performance, debugging, fragile systems |
| UX / Usability | Jakob Nielsen / NNGroup-inspired UX lens | Interface clarity, cognitive load, operator actionability |
